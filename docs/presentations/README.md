# IntelliPath presentation

[Download the PowerPoint](./IntelliPath_Path_Agent_Experience.pptx?raw=true)

The 12-slide English project presentation includes Seatrium branding, actual workspace screenshots, the IntelliPath path theme, Agent-to-Agent collaboration concepts, and the five access roles.

Open the file in desktop PowerPoint and start Slide Show to view the three animated GIFs and slide transitions. Static previews display still images.

The slides distinguish the current coordinator-based specialist search from the proposed sequential Agent-to-Agent workflow. Microsoft source logos are illustrative; those services are not connected. Maritime scenes and sample operational records illustrate the project and do not represent actual Seatrium operations. This is a project presentation, not an official Seatrium corporate publication.
